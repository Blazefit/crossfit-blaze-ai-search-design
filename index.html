CrossFit Blaze AI Search Acquisition Optimization Design

Date: 2026-05-15
Site: https://www.crossfitblaze.com
Local source: /Users/jasonanderson/Claude Code/cfblaze-revamp

Optimize CrossFit Blaze for new member acquisition across two primary entry points: CrossFit group classes and personal training. The work follows Google's AI search guidance by improving the same fundamentals that help traditional Search: crawlable pages, clear canonical URLs, helpful original content, complete local-business details, rich media context, and a strong page experience.

Goal

Optimize CrossFit Blaze for new member acquisition across two primary entry points:

  • CrossFit group classes for beginners, returning athletes, seasonal residents, and locals who want coaching plus community.
  • Personal training for active adults, seniors, post-rehab clients, hesitant beginners, and people who need a more private start.

The site should be easier for Google, AI answer systems, and humans to understand without creating AI-only content.

Source Guidance

Google's AI optimization guide emphasizes:

  • Keep using normal SEO fundamentals; there is no separate AI-specific trick.
  • Make pages crawlable, indexable, and technically clear.
  • Publish helpful, unique, people-first content.
  • Make page content easy to understand through headings, media, text, and structured data.
  • Avoid relying on unsupported AI-specific conventions such as llms.txt as a ranking mechanism.

Current Site Shape

The local source is a static HTML site with these public pages:

  • index.html
  • personal-training.html
  • pricing.html
  • schedule.html
  • free-trial.html
  • seniors.html
  • beginners.html
  • about.html
  • contact.html
  • sitemap.xml
  • assets/styles.css

The site already has strong brand positioning: owner-coached since 2009, scaled to the person, Naples local identity, personal training, seniors, beginners, and three free classes. The main gap is that the technical layer and page architecture do not yet make those strengths explicit enough for search engines and AI answer systems.

Proposed Approach

Use the full Approach C: technical SEO foundation plus acquisition-focused content improvements.

This approach intentionally does not chase AI-search gimmicks. It strengthens the facts, context, and crawlability that AI systems rely on when summarizing local businesses.

Technical Architecture

Canonical URLs

Add a <link rel="canonical"> tag to every HTML page using the preferred https://www.crossfitblaze.com/... URL.

Canonical targets:

  • Home: https://www.crossfitblaze.com/
  • Other pages: current .html URLs, unless hosting redirects are later changed to extensionless URLs.

Robots and Sitemap

Add robots.txt with:

  • Allow normal crawling.
  • Point crawlers to https://www.crossfitblaze.com/sitemap.xml.

Keep sitemap.xml aligned with the same canonical URL style.

Structured Data

Add JSON-LD structured data to the site. Use only stable factual information already present in the site or the CrossFit Blaze brand reference.

Recommended schema:

  • Sitewide LocalBusiness or SportsActivityLocation graph for CrossFit Blaze.
  • PostalAddress, GeoCoordinates if reliable coordinates are available.
  • OpeningHoursSpecification based on class/open hours.
  • sameAs links for Facebook, Instagram, Google Business Profile, and relevant CrossFit affiliate listing if available.
  • Offer entries for three free classes, drop-in, CrossFit membership, and personal training.
  • Service entries for CrossFit classes, personal training, beginners, and seniors/active adults.
  • FAQPage only where visible FAQ content exists on the page.

Schema must not invent claims, ratings, review counts, coordinates, or offers that are not visible or verifiable.

Social Metadata

Standardize Open Graph and Twitter metadata across all pages:

  • og:type
  • og:title
  • og:description
  • og:url
  • og:image
  • twitter:card
  • twitter:title
  • twitter:description
  • twitter:image

Use page-specific titles and descriptions, but keep the brand and Naples location visible.

Legacy URL Risk

Search results still appear to expose older WordPress-style paths, while the static source uses .html pages. The implementation should provide redirect guidance for the production host:

  • /about/ to /about.html
  • /personal-training/ to /personal-training.html
  • /pricing/ to /pricing.html
  • /schedule/ to /schedule.html
  • /contact/ to /contact.html
  • /free-trial/ to /free-trial.html
  • /beginners/ to /beginners.html
  • /seniors/ to /seniors.html

If host-level redirects are not available, canonical tags and internal links still reduce duplicate ambiguity, but redirects are preferred.

Content Architecture

Home Page

Position the home page as the decision hub:

  • Primary path: "Start with CrossFit classes" for people who want coaching, community, strength, and accountability.
  • Secondary path: "Start with personal training" for people who need private coaching, extra confidence, injury-aware training, or age-specific support.

Add a concise section that answers: "Which program should I start with?"

The answer should direct prospects without making them feel wrong:

  • Choose CrossFit classes if you want group coaching, community, and a complete workout plan.
  • Choose personal training if you want privacy, specific goals, confidence before class, injury-aware coaching, or active-aging support.

CrossFit Classes Acquisition

Strengthen the group-class path across home, beginners, schedule, pricing, and free-trial pages.

Content should answer:

  • What happens in a first CrossFit class?
  • Do I need to be in shape first?
  • How are workouts scaled?
  • What is included in coaching?
  • Why is CrossFit Blaze different from a big-box gym or bootcamp?
  • How do I book the three free classes?

Personal Training Acquisition

Strengthen personal training as a parallel acquisition route, not just an add-on.

Content should answer:

  • When is personal training the better first step?
  • Is it appropriate for older adults?
  • Can Jason work around medical history, past injuries, or post-rehab needs?
  • What does the first session look like?
  • How does someone transition from personal training into classes if they want to?

Local Authority

Make Naples and Collier County context explicit where natural:

  • Naples, FL
  • North Naples
  • Collier County
  • Seasonal residents and snowbirds
  • Active adults and retirees

Avoid keyword stuffing. The copy should still sound like CrossFit Blaze: local, direct, owner-coached, welcoming, and practical.

FAQ Strategy

Add visible FAQ sections where useful, then mark those sections with JSON-LD. Candidate pages:

  • beginners.html: first class, fitness level, scaling, soreness, booking.
  • personal-training.html: who it is for, injury history, seniors, pricing, first session.
  • pricing.html: free classes, contracts, drop-ins, personal training packs.

Do not add FAQ schema for questions that are not visible on the page.

Media and Accessibility

Improve media context without redesigning the site:

  • Use descriptive alt text for meaningful images.
  • Leave decorative avatars empty only when they do not add useful content.
  • Add width and height attributes or stable CSS sizing where practical to reduce layout shift.
  • Prefer real gym, facility, and coaching images over generic fitness imagery.

Internal Linking

Use internal links to make the acquisition paths obvious:

  • Home links to beginners.html, personal-training.html, pricing.html, schedule.html, and free-trial.html.
  • Beginners links to schedule, pricing, and free trial.
  • Personal training links to seniors, pricing, contact/free-trial path.
  • Pricing links back to classes and personal training explanation.
  • Schedule links to free trial and drop-in booking.

Non-Goals

  • No llms.txt implementation as an AI ranking tactic.
  • No hidden content for crawlers.
  • No fake reviews, fake ratings, invented coordinates, or exaggerated claims.
  • No broad visual redesign unless a technical/content change requires minor layout support.
  • No migration from static HTML to a framework.

Verification

Implementation should be verified by:

  • Opening the local site in a browser or static server.
  • Checking every page has exactly one canonical URL.
  • Checking structured data parses as valid JSON-LD.
  • Checking sitemap.xml and robots.txt.
  • Running a lightweight link check for internal links.
  • Inspecting visible content for duplicated, awkward, or keyword-stuffed copy.

Open Deployment Question

The local site folder is not its own git repository and appears untracked inside a broader Claude Code repository. Before production deployment, confirm how crossfitblaze.com is hosted and how these static files are published.

This spec intentionally avoids AI-search shortcuts. The optimization is built around factual local-business signals, helpful acquisition content, and clear technical structure.
